## 📌 INTRODUCCIÓN

Los **operadores** son símbolos especiales que le dicen a Python **qué hacer** con los datos.

Piensa en ellos como las **herramientas de un carpintero**:
- Una sierra **divide** (divide)
- Un martillo **une** (suma)
- Una regla **compara** (mayor, menor)

En Python hay **tres categorías principales** de operadores:

1. **Aritméticos** - Para cálculos matemáticos
2. **Comparación** - Para comparar valores
3. **Lógicos** - Para combinar condiciones

---

## ❓ ¿QUÉ SON LOS OPERADORES?

### Estructura Básica

```
operando1  operador  operando2
   10        +         5
   ↓         ↓         ↓
número    símbolo   número
```

**Resultado:** `15`

### Tipos de Operadores

```python
# Aritmético (operación matemática)
suma = 10 + 5              # 15

# Comparación (pregunta verdadero/falso)
es_mayor = 10 > 5          # True

# Lógico (combina condiciones)
condicion = (10 > 5) and (5 > 0)  # True
```

### ➗ División (/)


### 🔹 División Entera (//)

Devuelve solo la parte entera, **sin decimales**.

```python
a = 10
b = 3
print(a // b)  # 3 (descarta 0.333...)

# Otros ejemplos
print(20 // 7)   # 2
print(100 // 30) # 3
```

**En automatización:**
```python
# Calcular páginas de un documento
total_lineas = 1000
lineas_por_pagina = 40
total_paginas = total_lineas // lineas_por_pagina
print(total_paginas)  # 25 páginas completas
```

---

### 🔄 Módulo o Residuo (%)

Devuelve el **sobrante** después de una división.

```python
a = 10
b = 3
print(a % b)  # 1

# Explicación:
# 10 ÷ 3 = 3 con residuo 1
```

**Usos prácticos:**

#### 1. Verificar si un número es par o impar

```python
numero = 8
print(numero % 2)  # 0 (es par)

numero = 7
print(numero % 2)  # 1 (es impar)

# En automatización:
if numero % 2 == 0:
    print("Par")
else:
    print("Impar")
```

#### 2. Crear ciclos (cada N elementos)

```python
for i in range(1, 11):
    if i % 3 == 0:  # Cada 3
        print(f"{i} es múltiplo de 3")
# Resultado: 3, 6, 9 son múltiplos de 3
```

#### 3. Distribución equitativa

```python
# 17 manzanas entre 5 personas
manzanas = 17
personas = 5

manzanas_por_persona = manzanas // personas  # 3
manzanas_sobrantes = manzanas % personas      # 2

print(f"Cada persona recibe {manzanas_por_persona} manzana")
print(f"Sobran {manzanas_sobrantes} manzanas")
```

## 📊 PRECEDENCIA DE OPERADORES

Python sigue las reglas matemáticas: **multiplicación antes que suma**.

```python
resultado = 2 + 3 * 4

# ❌ NO hace: (2 + 3) * 4 = 20
# ✅ HACE: 2 + (3 * 4) = 14
print(resultado)  # 14
```

### Orden de Precedencia (de mayor a menor)

| Precedencia | Operador | Ejemplo |
|-------------|----------|---------|
| 1 (Mayor) | `**` | `2 ** 3 ** 2` = `2 ** 9` = 512 |
| 2 | `*, /, //, %` | `10 + 2 * 5` = `10 + 10` = 20 |
| 3 | `+, -` | `10 - 2 + 3` = `11` |
| 4 (Menor) | `==, !=, <, >` | Se evalúan después |

### Usa Paréntesis para Claridad

```python
# ❌ Confuso
resultado = 20 + 10 * 3 - 5 + 2 * 4

# ✅ Claro
resultado = (20 + 10) * 3 - (5 + 2) * 4
```

**En automatización:**
```python
# Calcular descuento
precio = 100
descuento_porcentaje = 10
impuesto_porcentaje = 19

# Claro con paréntesis
precio_con_descuento = precio * (1 - descuento_porcentaje / 100)
precio_final = precio_con_descuento * (1 + impuesto_porcentaje / 100)

print(f"Precio final: ${precio_final:.2f}")  # $107.10
```

## 🔄 OPERADORES DE ASIGNACIÓN COMPUESTA

### El Patrón

```python
# Forma larga
contador = contador + 1

# Forma corta (compuesta)
contador += 1
```

**Son exactamente lo mismo.**

### Todos los Operadores Compuestos

```python
x = 10

x += 5   # x = x + 5  → 15
x -= 3   # x = x - 3  → 12
x *= 2   # x = x * 2  → 24
x /= 4   # x = x / 4  → 6.0
x //= 2  # x = x // 2 → 3.0
x %= 2   # x = x % 2  → 1.0
x **= 3  # x = x ** 3 → 1
```

### En Automatización

```python
# Contador de procesados
registros_procesados = 0

# Por cada registro
registros_procesados += 1  # Más legible que += 1

# Total de dinero
total = 0
total += 100  # Deposita 100
total += 200  # Deposita 200
total -= 50   # Retira 50
print(total)  # 250
```

## ⚖️ OPERADORES DE COMPARACIÓN

Responden la pregunta: **¿Es verdadero o falso?**

**Siempre devuelven:** `True` o `False`

### 🟰 Igual (==)

```python
print(5 == 5)   # True
print(5 == 3)   # False
print("hola" == "hola")  # True

# Con variables
edad = 20
print(edad == 20)  # True
```

⚠️ **NO confundir con `=` (asignación):**

```python
edad = 20      # Asignación: "guarda 20 en edad"
edad == 20     # Comparación: "¿edad es igual a 20?"
```

---

### 🚫 Diferente (!=)

```python
print(5 != 3)   # True
print(5 != 5)   # False
print("hola" != "adiós")  # True
```

---

### ⬆️ Mayor que (>)

```python
print(10 > 5)   # True
print(3 > 8)    # False
print(5 > 5)    # False (igual NO es mayor)
```

---

### ⬇️ Menor que (<)

```python
print(3 < 8)    # True
print(10 < 5)   # False
print(5 < 5)    # False (igual NO es menor)
```

---

### ⬆️➡️ Mayor o igual (>=)

```python
print(10 >= 10) # True (igual cuenta)
print(10 >= 5)  # True
print(3 >= 8)   # False
```

---

### ⬇️➡️ Menor o igual (<=)

```python
print(5 <= 5)   # True (igual cuenta)
print(3 <= 8)   # True
print(10 <= 5)  # False
```

### Tabla de Comparación

| Expresión | Resultado |
|-----------|-----------|
| `5 == 5` | True |
| `5 != 3` | True |
| `10 > 5` | True |
| `3 < 8` | True |
| `5 >= 5` | True |
| `5 <= 5` | True |
| `5 == 3` | False |
| `5 >= 10` | False |

### En Automatización

## 🧠 OPERADORES LÓGICOS

Combinan **múltiples condiciones** para crear lógica más compleja.

### ✋ AND (y) - Todas deben ser verdaderas

```python
edad = 20
tiene_cedula = True

resultado = edad >= 18 and tiene_cedula
print(resultado)  # True (ambas son verdaderas)
```

**Síntaxis:**
```
condicion1 and condicion2
```

**Devuelve True SOLO si ambas son True**

### 👆 OR (o) - Al menos una debe ser verdadera

```python
tiene_dinero = True
tiene_tarjeta = False

puede_pagar = tiene_dinero or tiene_tarjeta
print(puede_pagar)  # True (al menos una es verdadera)
```

**Síntaxis:**
```
condicion1 or condicion2
```

**Devuelve True si al menos una es True**

### 🔄 NOT (no) - Invierte el valor

```python
es_estudiante = True
no_es_estudiante = not es_estudiante

print(no_es_estudiante)  # False
```

**Síntaxis:**
```
not condicion
```

**Convierte True en False y viceversa**

### Combinaciones Complejas

```python
edad = 20
tiene_cedula = True
es_buscado = False

# Múltiples AND
puede_entrar_discoteca = edad >= 18 and tiene_cedula and not es_buscado
print(puede_entrar_discoteca)  # True

# Múltiples OR
puede_conducir = tiene_licencia or tiene_permiso or es_instructor
print(puede_conducir)  # Depende de las variables

# Combinado
es_valido = (edad >= 18 and tiene_cedula) or es_mayor_de_edad_especial
```

## 📊 TABLAS DE VERDAD

### AND (Todas deben ser True)

```
A     | B     | A and B
------|-------|--------
True  | True  | True  ✅
True  | False | False ❌
False | True  | False ❌
False | False | False ❌
```

### OR (Al menos una debe ser True)

```
A     | B     | A or B
------|-------|-------
True  | True  | True  ✅
True  | False | True  ✅
False | True  | True  ✅
False | False | False ❌
```

### NOT (Invierte)

```
A     | not A
------|------
True  | False
False | True
```

## ⚡ EVALUACIÓN DE CORTOCIRCUITO

Python **detiene la evaluación** cuando ya conoce el resultado.

### AND - Cortocircuito en False

```python
# Si la primera es False, no evalúa la segunda
resultado = False and otra_condicion_complicada
# No evalúa otra_condicion_complicada
```

### OR - Cortocircuito en True

```python
# Si la primera es True, no evalúa la segunda
resultado = True or otra_condicion_complicada
# No evalúa otra_condicion_complicada
```

**Ventaja en automatización:**
```python
# Si no hay stock, no procesa el pago
if stock > 0 and procesar_pago():
    # Si stock es 0, procesar_pago() nunca se ejecuta
    pass
```

## 🤖 CASOS DE USO EN AUTOMATIZACIÓN

### 1. Validación de Acceso

```python
# Sistema de acceso
edad = 25
tiene_documento = True
cuenta_bloqueada = False

puede_entrar = (edad >= 18 and tiene_documento) and not cuenta_bloqueada

if puede_entrar:
    print("✅ Acceso concedido")
else:
    print("❌ Acceso denegado")
```

### 2. Cálculo de Descuentos

```python
# Sistema de descuentos
precio = 100
es_cliente_nuevo = True
es_cliente_premium = False
cantidad = 5

# Nuevos clientes: 10%, Premium: 15%, 5+ items: 5%
descuento = 0
if es_cliente_nuevo:
    descuento = 0.10
elif es_cliente_premium:
    descuento = 0.15

if cantidad >= 5:
    descuento += 0.05  # Adicional

precio_final = precio * (1 - descuento)
print(f"Precio final: ${precio_final:.2f}")
```

### 3. Validación de Datos de Formulario

```python
# Validar múltiples campos
nombre = "Juan García"
email = "juan@ejemplo.com"
edad = 25
aceptar_terminos = True

# Validaciones
nombre_valido = len(nombre) > 3 and nombre.isalpha() == False  # Permite espacios
email_valido = "@" in email and "." in email
edad_valida = 18 <= edad <= 100
terminos_aceptados = aceptar_terminos == True

# Resultado final
formulario_valido = nombre_valido and email_valido and edad_valida and terminos_aceptados

if formulario_valido:
    print("✅ Formulario aceptado")
else:
    print("❌ Hay errores en el formulario")
```

### 4. Control de Inventario

```python
# Sistema de inventario
stock = 5
stock_minimo = 10
precio = 50
precio_maximo = 100

# Verificar condiciones
necesita_reorden = stock < stock_minimo
precio_dentro_rango = precio <= precio_maximo
puede_vender = stock > 0

if necesita_reorden:
    print("⚠️ Hacer pedido")

if puede_vender and precio_dentro_rango:
    print("✅ Puede venderse")
else:
    print("❌ No puede venderse")
```

### 5. Decisiones Complejas en APIs

```python
# Procesar respuesta de API
status_codigo = 200
tiene_datos = True
datos_validos = True
requiere_autenticacion = False

# Decidir qué hacer
if status_codigo == 200 and tiene_datos and datos_validos:
    print("✅ Procesar datos")
elif status_codigo == 401 or requiere_autenticacion:
    print("🔒 Requiere autenticación")
elif status_codigo >= 500:
    print("❌ Error del servidor")
else:
    print("⚠️ Error desconocido")
```

## ❌ ERRORES COMUNES

### Error 1: Confundir = con ==

```python
# ❌ Error
if edad = 18:  # SyntaxError: invalid syntax
    print("Eres mayor de edad")

# ✅ Correcto
if edad == 18:
    print("Eres mayor de edad")
```

### Error 2: Olvidar paréntesis en lógica compleja

```python
# ❌ Confuso
if edad >= 18 and tiene_cedula and not es_buscado or es_inspector:
    # ¿Cuál es el orden de evaluación?
    pass

# ✅ Claro
if (edad >= 18 and tiene_cedula and not es_buscado) or es_inspector:
    # Ahora es obvio
    pass
```

### Error 3: Olvidar que / siempre devuelve float

```python
# ❌ Problema
resultado = 10 / 5
print(resultado)  # 2.0 (no es 2)

# ✅ Solución
resultado = 10 // 5  # División entera
print(resultado)  # 2
```

### Error 4: No usar cortocircuito eficientemente

```python
# ❌ Ineficiente
if len(lista) > 0 and lista[0] == "algo":
    # Si lista está vacía, lista[0] causará error

# ✅ Eficiente (cortocircuito)
if lista and lista[0] == "algo":
    # Si lista está vacía, no evalúa lista[0]
```
