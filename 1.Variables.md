## 🎯 CONCEPTOS FUNDAMENTALES

### ¿Por qué las variables son lo más importante?

Las variables son el **corazón de cualquier programa**. Sin ellas:

```python
# ❌ Sin variables - Código confuso
print("Cristian" + " gana " + str(50000) + " mensualmente")
print(50000 * 12)  # ¿Qué es 50000? ¿Por qué lo multiplicas por 12?
```

Con variables:
```python
# ✅ Con variables - Código claro
nombre = "Cristian"
salario_mensual = 50000
salario_anual = salario_mensual * 12

print(f"{nombre} gana {salario_mensual} mensualmente")
print(f"Su salario anual es: {salario_anual}")
```

**La diferencia:**
- Código legible y mantenible
- Fácil de debuggear
- Otras personas (y tú en el futuro) entienden qué hace el código
- Se pueden reutilizar valores sin escribir los números manualmente

## 📋 ¿QUÉ ES UNA VARIABLE?

Una variable es un **contenedor con nombre** que almacena un valor en la memoria de la computadora.

### Visualización Mental

```
┌────────────────────────────────────────┐
│       MEMORIA DE LA COMPUTADORA        │
├────────────────────────────────────────┤
│                                        │
│  nombre ──────→ "Cristian"            │
│  edad ────────→ 20                    │
│  salario ─────→ 50000.00              │
│  es_empleado ─→ True                  │
│                                        │
└────────────────────────────────────────┘
```

Cada variable:
- Tiene un **nombre** (etiqueta)
- Apunta a una **dirección de memoria**
- Contiene un **valor** (dato)
- Tiene un **tipo** (str, int, float, bool, etc.)

---

## 💾 MEMORIA Y ALMACENAMIENTO

### Cómo Python almacena variables

Cuando escribes:
```python
edad = 20
```

Python hace esto internamente:

1. **Reserva espacio en memoria** para guardar el número 20
2. **Crea una referencia** llamada `edad` que apunta a ese espacio
3. **Almacena el tipo** (sabe que es un `int`)

### ID de una variable (dirección de memoria)

```python
edad = 20
print(id(edad))  # Muestra la dirección de memoria: 140734456789456
```

Esto es importante en automatización cuando trabajas con archivos y bases de datos:

```python
# En automatización: conexión a base de datos
conexion_db = conectar_a_base_datos()
# Python reserva memoria para la conexión y crea la referencia
print(id(conexion_db))  # Muestra dónde está almacenada en memoria
```

## ⚠️ ASIGNACIÓN VS COMPARACIÓN

Este es uno de los **errores más comunes** de principiantes.

| Operador | Significado | Contexto | Ejemplo |
|----------|------------|---------|---------|
| `=` | Asignación | Guardar un valor | `edad = 20` |
| `==` | Comparación | ¿Son iguales? | `if edad == 20:` |

### Ejemplos Prácticos

```python
# ✅ CORRECTO - Asignación
edad = 20  # "Guarda 20 en edad"

# ❌ INCORRECTO en muchos contextos - Confundir = con ==
if edad = 20:  # Error de sintaxis
    print("Eres mayor de edad")

# ✅ CORRECTO - Comparación
if edad == 20:  # "¿edad es igual a 20?"
    print("Eres mayor de edad")
```

En automatización es crítico:

```python
# Automatización: verificar si un archivo fue encontrado
archivo_existe = False  # Asignación

if archivo_existe == True:  # Comparación
    print("Procesando archivo...")
```

## 🔄 REASIGNACIÓN Y MUTABILIDAD

### Variables pueden cambiar

Las variables NO son constantes. Puedes cambiar su valor múltiples veces:

```python
dinero = 100
print(f"Dinero inicial: {dinero}")  # 100

dinero = 200  # Reasignación - el anterior se pierde
print(f"Dinero después del depósito: {dinero}")  # 200

dinero = dinero - 50  # Reasignación con operación
print(f"Dinero después del retiro: {dinero}")  # 150
```

### Cambiar tipo de dato

Una variable puede cambiar de tipo:

```python
valor = 20  # int
print(type(valor))  # <class 'int'>

valor = "veinte"  # Ahora es str
print(type(valor))  # <class 'str'>

valor = 20.5  # Ahora es float
print(type(valor))  # <class 'float'>
```

**En automatización**, esto ocurre frecuentemente:

```python
# Datos de un API que puede devolver números o strings
precio = 99.99  # float
precio = "99.99"  # str (del API)
precio = float(precio)  # Convertir de nuevo a float
```

## 🎯 REGLAS Y CONVENCIONES DE NOMBRES

### Reglas Obligatorias (Sintaxis Python)

Las siguientes son **errores de sintaxis**:

```python
# ❌ Error: No puede empezar con número
2nombre = "Juan"

# ❌ Error: No puede tener espacios
nombre completo = "Juan Pérez"

# ❌ Error: No puede usar palabras reservadas
class = 10  # 'class' es una palabra reservada
def = "función"  # 'def' es palabra reservada
if = True  # 'if' es palabra reservada

# ❌ Error: No puede usar caracteres especiales (excepto _)
nombre-completo = "Juan"  # El guión se interpreta como resta
email@ = "juan@correo.com"

# ✅ Válidos
_nombre = "Juan"  # Puede empezar con guión bajo
nombre_ = "Juan"  # Puede terminar con guión bajo
nombre123 = "Juan"  # Puede contener números (no al inicio)
NombreCompleto = "Juan"  # Puede ser camelCase (pero no es lo común en Python)
```

### Convenciones Profesionales (PEP 8 - Python Enhancement Proposal 8)

PEP 8 es la **guía de estilo oficial de Python**. Las empresas la usan.

#### Snake_case para variables

```python
# ✅ RECOMENDADO en Python
nombre_usuario = "Juan"

precio_total = 99.99
cantidad_productos = 10
es_cliente_premium = True

nombreUsuario = "Juan"  # camelCase (JavaScript/Java)
NombreUsuario = "Juan"  # PascalCase (para clases)
NOMBRE_USUARIO = "Juan"  # SCREAMING_SNAKE_CASE (constantes)
```

#### Nombres descriptivos

```python
# ❌ Malo - No se entiende
a = 100
b = 200
c = a + b
print(c)

# ✅ Bueno - Es claro
precio_producto = 100
precio_envio = 200
precio_total = precio_producto + precio_envio
print(precio_total)
```

#### Nombres específicos del dominio


## 📝 MOSTRAR VARIABLES CON PRINT()

### Formas de mostrar variables

#### Opción 1: Concatenación con + (Antigua)

```python
nombre = "Cristian"
edad = 20

print("Mi nombre es " + nombre + " y tengo " + str(edad) + " años")
# Mi nombre es Cristian y tengo 20 años
```

**Problemas:**
- Difícil de leer
- Necesitas convertir números a strings con `str()`
- Propenso a errores

#### Opción 2: .format() (Intermedia)

```python
nombre = "Cristian"
edad = 20

print("Mi nombre es {} y tengo {} años".format(nombre, edad))
# Mi nombre es Cristian y tengo 20 años
```

**Mejor que concatenación, pero aún confuso con muchos valores.**

#### Opción 3: f-strings (MODERNA - Recomendada) ⭐

```python
nombre = "Cristian"
edad = 20
altura = 1.75

# Básico
print(f"Hola {nombre}")  # Hola Cristian

# Múltiples variables
print(f"Me llamo {nombre}, tengo {edad} años y mido {altura}m")
# Me llamo Cristian, tengo 20 años y mido 1.75m

# Con operaciones
print(f"El próximo año tendré {edad + 1} años")  # El próximo año tendré 21 años

# Con formato de decimales
precio = 99.99
print(f"Precio: ${precio:.2f}")  # Precio: $99.99

# Con separadores de miles
dinero = 1000000
print(f"Dinero: ${dinero:,}")  # Dinero: $1,000,000
```

**Ventajas:**
- Legible y claro
- No necesitas `str()` para números
- Puedes hacer operaciones dentro
- Es el estándar moderno

## 🌐 SCOPE (ALCANCE) BÁSICO

El scope define **dónde una variable existe y puede usarse**.

### Variables Globales (existen en todo el programa)

```python
# Variable global - existe en todo el programa
nombre = "Cristian"

print(nombre)  # ✅ Funciona - Cristian
```

### Variables Locales (existen solo dentro de una función)

```python
# Esta variable local solo existe dentro de la función
def saludar():
    mensaje = "Hola"
    print(mensaje)  # ✅ Funciona dentro de la función

saludar()  # Hola

print(mensaje)  # ❌ Error: NameError - no existe fuera de la función
```

En automatización, esto es importante:

```python
# Automatización: procesar archivo
def procesar_archivo(ruta):
    contenido = leer_archivo(ruta)  # Variable local
    datos = procesar_datos(contenido)  # Variable local
    return datos

resultado = procesar_archivo("archivo.txt")
print(resultado)  # ✅ Funciona

print(contenido)  # ❌ Error - solo existe dentro de la función
```

## 🤖 CASOS DE USO EN AUTOMATIZACIÓN

### 1. Automatización de Procesos Manuales

```python
# Automatizar: Calcular nómina de empleados
nombre_empleado = "Juan García"
dias_trabajados = 20
valor_dia = 50000
descuento_impuestos = 0.08

salario_bruto = dias_trabajados * valor_dia
descuento = salario_bruto * descuento_impuestos
salario_neto = salario_bruto - descuento

print(f"Empleado: {nombre_empleado}")
print(f"Salario bruto: ${salario_bruto:,}")
print(f"Descuentos: ${descuento:,}")
print(f"Salario a recibir: ${salario_neto:,}")
```

### 2. Procesamiento de Datos de APIs

```python
# Automatizar: Procesar datos de un API
respuesta_api = {
    "usuario": "cristian_22",
    "edad": "25",  # Viene como string
    "ciudad": "Medellín",
    "activo": "true"  # Viene como string
}

usuario = respuesta_api["usuario"]
edad = int(respuesta_api["edad"])  # Convertir a número
ciudad = respuesta_api["ciudad"]
esta_activo = respuesta_api["activo"] == "true"  # Convertir a bool

print(f"{usuario} ({edad} años) de {ciudad}")
print(f"Cuenta activa: {esta_activo}")
```

### 3. Web Scraping (Extracción de datos de sitios web)

```python
# Automatizar: Extraer información de un producto
nombre_producto = "Laptop Dell XPS"
precio_original = 1299.99
descuento_porcentaje = 15

precio_descuento = precio_original * (descuento_porcentaje / 100)
precio_final = precio_original - precio_descuento

print(f"Producto: {nombre_producto}")
print(f"Precio original: ${precio_original}")
print(f"Descuento ({descuento_porcentaje}%): ${precio_descuento:.2f}")
print(f"Precio final: ${precio_final:.2f}")
```

### 4. Procesamiento de Archivos

```python
# Automatizar: Procesar datos de un archivo CSV
nombre_archivo = "ventas.csv"
cantidad_registros = 1000
registros_procesados = 950
registros_con_error = 50

porcentaje_exito = (registros_procesados / cantidad_registros) * 100
porcentaje_error = (registros_con_error / cantidad_registros) * 100

print(f"Archivo: {nombre_archivo}")
print(f"Total de registros: {cantidad_registros}")
print(f"Procesados correctamente: {registros_procesados} ({porcentaje_exito:.1f}%)")
print(f"Con error: {registros_con_error} ({porcentaje_error:.1f}%)")
```

## ❌ ERRORES COMUNES

### Error 1: Olvidar comillas en strings

```python
# ❌ Incorrecto
nombre = Cristian
print(nombre)  # NameError: name 'Cristian' is not defined

# ✅ Correcto
nombre = "Cristian"
print(nombre)  # Cristian
```

### Error 2: Confundir tipos de datos

```python
# ❌ Problema
edad = "25"  # Es string
print(edad + 5)  # TypeError: can only concatenate str (not "int") to str

# ✅ Solución
edad = 25  # Es número
print(edad + 5)  # 30
```

### Error 3: Usar variables antes de crearlas

```python
# ❌ Incorrecto
print(nombre)  # NameError: name 'nombre' is not defined
nombre = "Cristian"

# ✅ Correcto
nombre = "Cristian"
print(nombre)  # Cristian
```

### Error 4: Nombres poco descriptivos

```python
# ❌ Confuso
x = 100
y = 20
z = x * y
print(z)  # ¿Qué es esto?

# ✅ Claro
precio_unitario = 100
cantidad_productos = 20
precio_total = precio_unitario * cantidad_productos
print(precio_total)  # 2000 - Está claro
```

### Error 5: Olvidar convertir input()

```python
# ❌ Incorrecto
numero = input("Ingresa un número: ")
print(numero + 10)  # TypeError: can only concatenate str (not "int") to str

# ✅ Correcto
numero = int(input("Ingresa un número: "))
print(numero + 10)  # Funciona correctamente
```
