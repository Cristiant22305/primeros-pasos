## 📌 INTRODUCCIÓN

Hasta ahora hemos hecho esto:

```python
nombre = "Cristian"
print(nombre)
```

**El problema:** El valor ya está en el código. Si otra persona ejecuta el programa, verá siempre `Cristian`.

**La solución:** Permitir que el usuario **ingrese sus propios datos**.

**Para eso existen dos funciones fundamentales:**

1. **`print()`** - Mostrar información al usuario
2. **`input()`** - Recibir información del usuario

---

## ⚡ ¿POR QUÉ ES IMPORTANTE?

Sin entrada/salida, los programas serían **inútiles**:

```python
# Sin entrada/salida (inútil)
a = 10
b = 5
resultado = a + b

# Con entrada/salida (útil)
a = float(input("Ingresa el primer número: "))
b = float(input("Ingresa el segundo número: "))
resultado = a + b
print(f"La suma es {resultado}")
```

Con entrada/salida, tu programa es **interactivo** y **reutilizable**.

## 📤 SALIDA DE DATOS: print()

### Básico: Mostrar Texto

```python
print("Hola mundo")
```

**Salida:**
```
Hola mundo
```

### Mostrar Números

```python
print(20)
print(3.14)
print(True)
```

**Salida:**
```
20
3.14
True
```

### Mostrar Variables

```python
nombre = "Cristian"
edad = 20
print(nombre)
print(edad)
```

**Salida:**
```
Cristian
20
```

### Mostrar Múltiples Valores

```python
nombre = "Cristian"
edad = 20
print(nombre, edad)
```

**Salida:**
```
Cristian 20
```

⚠️ **Nota:** Python agrega un espacio automáticamente entre los valores.

### El Problema del Enfoque Anterior

```python
nombre = "Cristian"
edad = 20
ciudad = "Medellín"

print("Mi nombre es", nombre, "y tengo", edad, "años y vivo en", ciudad)
```

**Funciona, pero:**
- Difícil de leer
- Propenso a errores
- Difícil de mantener

## 📝 FORMATEO DE STRINGS

### Opción 1: Concatenación Antigua

```python
nombre = "Cristian"
print("Hola " + nombre)
```

**Resultado:**
```
Hola Cristian
```

❌ **Antiguo - No lo uses**

### Opción 2: F-strings (RECOMENDADO) ⭐

```python
nombre = "Cristian"
print(f"Hola {nombre}")
```

**Resultado:**
```
Hola Cristian
```

✅ **Moderno - Úsalo siempre**

**La `f` significa:** "Python, dentro de las llaves habrá variables o expresiones"

### Ejemplos Prácticos con F-strings

```python
nombre = "Juan"
edad = 25
ciudad = "Bogotá"

print(f"Me llamo {nombre}")
print(f"Tengo {edad} años")
print(f"Vivo en {ciudad}")
print(f"{nombre} tiene {edad} años y vive en {ciudad}")
```

**Salida:**
```
Me llamo Juan
Tengo 25 años
Vivo en Bogotá
Juan tiene 25 años y vive en Bogotá
```

## ⚙️ F-STRINGS AVANZADAS

### Operaciones Dentro de F-strings

```python
a = 10
b = 5

print(f"La suma es {a + b}")
print(f"La multiplicación es {a * b}")
print(f"El doble de {a} es {a * 2}")
```

**Salida:**
```
La suma es 15
La multiplicación es 50
El doble de 10 es 20
```

### Formateo de Decimales

```python
precio = 99.9999
print(f"Precio: ${precio}")
print(f"Precio: ${precio:.2f}")
```

**Salida:**
```
Precio: $99.9999
Precio: $99.99
```

`.2f` significa: "muestra 2 decimales"

### Más Ejemplos de Formateo

```python
pi = 3.14159265

print(f"2 decimales: {pi:.2f}")      # 3.14
print(f"3 decimales: {pi:.3f}")      # 3.142
print(f"4 decimales: {pi:.4f}")      # 3.1416
```

### Alinear Texto

```python
nombre = "Juan"
edad = 25

print(f"Nombre: {nombre:<15} Edad: {edad}")
print(f"Nombre: {nombre:>15} Edad: {edad}")
print(f"Nombre: {nombre:^15} Edad: {edad}")
```

**Salida:**
```
Nombre: Juan            Edad: 25
Nombre:            Juan Edad: 25
Nombre:     Juan        Edad: 25
```

- `<` = Alineado a la izquierda
- `>` = Alineado a la derecha
- `^` = Centrado

### Tabla Formateada

```python
print(f"{'Nombre':<15} {'Edad':>5} {'Ciudad':<10}")
print(f"{'-'*15} {'-'*5} {'-'*10}")
print(f"{'Juan':<15} {25:>5} {'Bogotá':<10}")
print(f"{'María':<15} {30:>5} {'Medellín':<10}")
```

**Salida:**
```
Nombre          Edad  Ciudad    
-------------- ----- ----------
Juan              25 Bogotá    
María             30 Medellín  
```

## 📥 ENTRADA DE DATOS: input()

### Básico

```python
nombre = input("¿Cuál es tu nombre? ")
print(nombre)
```

**Si el usuario escribe `Cristian`:**
```
¿Cuál es tu nombre? Cristian

```

### Con Variables

```python
nombre = input("Nombre: ")
edad = input("Edad: ")
ciudad = input("Ciudad: ")

print(f"Hola {nombre}, tienes {edad} años y vives en {ciudad}")
```

**Si el usuario ingresa:**
```

Edad: 25
Ciudad: Bogotá
```

**Salida:**
```
Hola Juan, tienes 25 años y vives en Bogotá
```

```python
edad = input("Edad: ")

```

**Si escribes `25`, Python muestra:**
```

```

**No es un número. Es texto.**

## 🔄 CONVERSIÓN DE DATOS

### El Error Clásico

```python
edad = input("Edad: ")
print(edad + 5)
```

**Si escribes `20`:**

```
TypeError: can only concatenate str (not "int") to str
```

Python intenta hacer `"20" + 5` y falla.

### La Solución: Convertir el Tipo

```python
edad = int(input("Edad: "))
print(edad + 5)
```

**Si escribes `20`:**
```
25
```

### Tabla de Conversiones

| Necesitas | Código | Ejemplo |
|-----------|--------|---------|
| Texto | `input()` | `nombre = input("Nombre: ")` |
| Número entero | `int(input())` | `edad = int(input("Edad: "))` |
| Número decimal | `float(input())` | `altura = float(input("Altura: "))` |
| Booleano | `input() == "si"` | `aceptar = input("¿Aceptas?") == "si"` |

### Ejemplos de Conversiones

```python
# Texto (automático)
nombre = input("Nombre: ")  # Ya es string

# Número entero
cantidad = int(input("Cantidad: "))

# Número decimal
precio = float(input("Precio: "))

# Booleano (pregunta sí/no)
aceptar = input("¿Aceptas los términos? (sí/no): ") == "sí"
```

### Conversiones Múltiples en Una Línea

```python
edad = int(input("Edad: "))
altura = float(input("Altura: "))
nombre = input("Nombre: ").strip()  # Limpia espacios

print(f"{nombre} tiene {edad} años y mide {altura}m")
```

## 🔤 SECUENCIAS DE ESCAPE

Caracteres especiales que se escriben con `\`.

### Tabla de Secuencias Útiles

| Secuencia | Significado | Ejemplo |
|-----------|-------------|---------|
| `\n` | Salto de línea | `"Hola\nMundo"` |
| `\t` | Tabulación | `"Nombre\tEdad"` |
| `\\` | Barra invertida | `"Ruta\\archivo"` |
| `\"` | Comilla doble | `"Dice \"Hola\""` |
| `\'` | Comilla simple | `'Dice \'Hola\''` |

### Ejemplos

#### Salto de Línea (\n)

```python
print("Python\nJava\nC++")
```

**Salida:**
```
Python
Java
C++
```

#### Tabulación (\t)

```python
print("Nombre\tEdad\tCiudad")
print("Juan\t25\tBogotá")
print("María\t30\tMedellín")
```

**Salida:**
```
Nombre	Edad	Ciudad
Juan	25	Bogotá
María	30	Medellín
```

#### Barra Invertida (\\)

```python
print("Ruta del archivo: C:\\Users\\Juan\\archivo.txt")
```

**Salida:**
```
Ruta del archivo: C:\Users\Juan\archivo.txt
```

#### Comillas

```python
print("Dijo: \"Hola mundo\"")
print('Dijo: \'Hola mundo\'')
```

**Salida:**
```
Dijo: "Hola mundo"
Dijo: 'Hola mundo'
```

### Líneas Vacías

```python
print("Inicio")
print()
print("Fin")
```

**Salida:**
```
Inicio

Fin
```

## ✅ VALIDACIÓN BÁSICA

### Verificar que No Esté Vacío

```python
nombre = input("Nombre: ").strip()

if nombre == "":
    print("❌ El nombre no puede estar vacío")
else:
    print(f"✅ Bienvenido {nombre}")
```

### Verificar que Sea un Número Válido

```python
try:
    edad = int(input("Edad: "))
    if 0 < edad < 150:
        print(f"✅ Edad válida: {edad}")
    else:
        print("❌ Edad fuera de rango")
except ValueError:
    print("❌ Debes ingresar un número")
```

### Verificar Longitud Mínima

```python
contraseña = input("Contraseña: ")

if len(contraseña) < 8:
    print("❌ La contraseña debe tener al menos 8 caracteres")
else:
    print("✅ Contraseña válida")
```

### Verificar que Contenga Solo Letras

```python
nombre = input("Nombre: ")

if nombre.isalpha():
    print(f"✅ Nombre válido: {nombre}")
else:
    print("❌ El nombre solo puede contener letras")
```

## 🤖 CASOS DE USO EN AUTOMATIZACIÓN

### 1. Formulario de Registro

```python
print("=== FORMULARIO DE REGISTRO ===\n")

nombre = input("Nombre: ").strip()
email = input("Email: ").strip()
edad = int(input("Edad: "))

print("\n--- CONFIRMACIÓN ---")
print(f"Nombre: {nombre}")
print(f"Email: {email}")
print(f"Edad: {edad}")
print("✅ Registro completado")
```

### 2. Calculadora Interactiva

```python
print("=== CALCULADORA ===\n")

a = float(input("Primer número: "))
b = float(input("Segundo número: "))
operacion = input("Operación (+, -, *, /): ")

if operacion == "+":
    resultado = a + b
elif operacion == "-":
    resultado = a - b
elif operacion == "*":
    resultado = a * b
elif operacion == "/":
    resultado = a / b
else:
    resultado = None

if resultado is not None:
    print(f"\n{a} {operacion} {b} = {resultado}")
```

### 3. Generador de Recibos

```python
print("=== GENERADOR DE RECIBOS ===\n")

nombre_producto = input("Producto: ")
cantidad = int(input("Cantidad: "))
precio_unitario = float(input("Precio unitario: "))

subtotal = cantidad * precio_unitario
impuesto = subtotal * 0.19
total = subtotal + impuesto

print("\n" + "="*40)
print(f"{'RECIBO':^40}")
print("="*40)
print(f"Producto: {nombre_producto}")
print(f"Cantidad: {cantidad}")
print(f"Precio unitario: ${precio_unitario:.2f}")
print("-"*40)
print(f"Subtotal: ${subtotal:.2f}")
print(f"Impuesto (19%): ${impuesto:.2f}")
print("-"*40)
print(f"TOTAL: ${total:.2f}")
print("="*40)
```

### 4. Conversor de Temperaturas

```python
print("=== CONVERSOR DE TEMPERATURAS ===\n")

celsius = float(input("Ingresa temperatura en °C: "))
fahrenheit = (celsius * 9/5) + 32
kelvin = celsius + 273.15

print(f"\n{celsius}°C = {fahrenheit:.2f}°F")
print(f"{celsius}°C = {kelvin:.2f}K")
```

### 5. Calculadora de IMC

```python
print("=== CALCULADORA DE IMC ===\n")

peso = float(input("Peso (kg): "))
altura = float(input("Altura (m): "))

imc = peso / (altura ** 2)

print(f"\nTu IMC: {imc:.2f}")

if imc < 18.5:
    categoria = "Bajo peso"
elif imc < 25:
    categoria = "Peso normal"
elif imc < 30:
    categoria = "Sobrepeso"
else:
    categoria = "Obesidad"

print(f"Categoría: {categoria}")
```

## ❌ ERRORES COMUNES

### Error 1: Olvidar Convertir input()

```python
# ❌ Error
edad = input("Edad: ")
print(edad + 10)  # TypeError

# ✅ Correcto
edad = int(input("Edad: "))
print(edad + 10)  # Funciona
```

### Error 2: No Usar F-strings

```python
# ❌ Difícil de leer
print("Hola " + nombre + ", tienes " + str(edad) + " años")

# ✅ Claro
print(f"Hola {nombre}, tienes {edad} años")
```

### Error 3: No Limpiar Espacios

```python
# ❌ Problema
nombre = input("Nombre: ")  # " Juan  "
print(f"Hola {nombre}")     # "Hola  Juan  "

# ✅ Solución
nombre = input("Nombre: ").strip()  # "Juan"
print(f"Hola {nombre}")              # "Hola Juan"
```

### Error 4: Formato Incorrecto

```python
# ❌ Muchos decimales
print(f"Precio: ${99.9999}")  # $99.9999

# ✅ Formato correcto
print(f"Precio: ${99.9999:.2f}")  # $99.99
```

### Error 5: No Validar Entrada

```python
# ❌ Sin validación
edad = int(input("Edad: "))  # ¿Qué pasa si escriben "abc"?

# ✅ Con validación
try:
    edad = int(input("Edad: "))
    if 0 < edad < 150:
        print("Válido")
except ValueError:
    print("Debes ingresar un número")
```

#### Ejercicio 4.1: Simulador de Compra

```python
# TODO: Simula una compra de múltiples productos
# - Ingresa productos y precios
# - Calcula subtotal, descuento, IVA y total
# - Aplica descuento si total > $100
```

**Solución:**
```python
print("=== CARRITO DE COMPRAS ===\n")

productos = {}
print("Ingresa productos (escribe 'fin' para terminar):\n")

while True:
    producto = input("Producto (o 'fin'): ").strip()
    if producto.lower() == "fin":
        break
    
    cantidad = int(input("Cantidad: "))
    precio = float(input("Precio unitario: "))
    productos[producto] = {"cantidad": cantidad, "precio": precio}

# Cálculos
subtotal = sum(p["cantidad"] * p["precio"] for p in productos.values())
descuento = subtotal * 0.1 if subtotal > 100 else 0
subtotal_descuento = subtotal - descuento
iva = subtotal_descuento * 0.19
total = subtotal_descuento + iva

# Imprime factura
print("\n" + "="*60)
print(f"{'FACTURA':^60}")
print("="*60)

for producto, datos in productos.items():
    subtotal_item = datos["cantidad"] * datos["precio"]
    print(f"{producto:<30} {datos['cantidad']:>3} x ${datos['precio']:>8.2f} = ${subtotal_item:>10.2f}")

print("-"*60)
print(f"Subtotal:         ${subtotal:>40.2f}")
if descuento > 0:
    print(f"Descuento (10%):  ${descuento:>40.2f}")
print(f"IVA (19%):        ${iva:>40.2f}")
print("-"*60)
print(f"TOTAL:            ${total:>40.2f}")
print("="*60)
```

```python
from datetime import datetime, timedelta
```
