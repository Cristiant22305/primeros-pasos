## 📌 Introducción

Las condicionales son la base de la lógica en programación. Permiten que tu programa tome decisiones basadas en condiciones.

Ejemplo del mundo real:
- Si es mayor de edad, puede votar
- Si llueve, lleva paraguas
- Si el saldo es suficiente, permite la compra

En Python usaremos `if`, `elif` y `else` para controlar el flujo del programa.

---

## ❓ ¿Qué significa if?

`if` significa: "Si esta condición es verdadera, ejecuta este bloque de código."

Sintaxis básica:

```python
if condicion:
    instrucciones
```

Ejemplo:

```python
edad = 20

if edad >= 18:
    print("Eres mayor de edad")
```

Resultado:
```
Eres mayor de edad
```

---

## 📝 Sintaxis y dos puntos

Observa los dos puntos `:` — son **obligatorios**. Python los usa para indicar que comienza un bloque de código.

```python
if condicion:      # ← Dos puntos OBLIGATORIOS
    codigo         # ← Indentado (4 espacios o 1 TAB)
```

Sin los dos puntos:

```python
if edad >= 18      # ❌ Error de sintaxis
    print("Mayor")
```

---

## 🔍 Indentación (MUY IMPORTANTE)

Los espacios antes de las líneas se llaman **indentación**. Python usa la indentación para saber qué instrucciones pertenecen al `if`.

Correcto:

```python
if edad >= 18:
    print("Puedes entrar")
    print("Bienvenido")
```

Incorrecto (error de indentación):

```python
if edad >= 18:
print("Puedes entrar")  # ❌ Sin indentación
```

Ejemplo visual:

```python
if condicion:
    linea_1           # Dentro del if
    linea_2           # Dentro del if
    linea_3           # Dentro del if
print("Fuera del if")  # No indentado, fuera del if
```

## else

¿Qué pasa si queremos hacer algo cuando la condición sea **falsa**? Usamos `else`.

```python
edad = 15

if edad >= 18:
    print("Puedes entrar")
else:
    print("No puedes entrar")
```

Resultado:
```
No puedes entrar
```

Traducción mental:

Si edad >= 18 → entra
Si no (else) → no entra

---

## elif

Cuando hay **más de dos opciones** usamos `elif` (else if).

Ejemplo de una escala de calificaciones:

```python
nota = 4.5

if nota >= 5:
    print("Excelente")
elif nota >= 4:
    print("Bueno")
elif nota >= 3:
    print("Aprobado")
else:
    print("Reprobado")
```

Resultado:
```
Bueno
```

**Cómo lo evalúa Python:**

Python pregunta por la primera condición (`if`). Si es falsa, pasa a la siguiente (`elif`). Cuando encuentra la primera verdadera, ejecuta su bloque y **termina** (ignora el resto).

> **Error común**: usar varios `if` independientes cuando las opciones son excluyentes — esto puede imprimir varias respuestas.

Incorrecto:

```python
nota = 4.5

if nota >= 5:
    print("Excelente")

if nota >= 4:
    print("Bueno")

if nota >= 3:
    print("Aprobado")
```

Salida incorrecta:
```
Bueno
Aprobado
```

Por eso se usa `if` / `elif` / `else` cuando las condiciones son mutuamente excluyentes.

## 📊 Operadores de comparación

| Operador | Significado | Ejemplo |
|----------|-------------|---------|
| `==` | Igual | `5 == 5` → True |
| `!=` | No igual | `5 != 3` → True |
| `>` | Mayor que | `5 > 3` → True |
| `<` | Menor que | `3 < 5` → True |
| `>=` | Mayor o igual | `5 >= 5` → True |
| `<=` | Menor o igual | `3 <= 5` → True |

Ejemplos:

```python
x = 10

if x == 10:
    print("x es igual a 10")

if x != 5:
    print("x no es igual a 5")

if x > 7:
    print("x es mayor que 7")
```

## 🔗 Operadores lógicos dentro de if

Puedes combinar condiciones con `and`, `or` y `not`.

### and

**Ambas condiciones** deben ser verdaderas.

```python
edad = 20
tiene_documento = True

if edad >= 18 and tiene_documento:
    print("Puede entrar")
```

Tabla de verdad:

| A | B | A and B |
|---|---|---------|
| True | True | True |
| True | False | False |
| False | True | False |
| False | False | False |

### or

**Basta con que una** condición sea verdadera.

```python
es_profesor = False
es_director = True

if es_profesor or es_director:
    print("Acceso permitido")
```

Tabla de verdad:

| A | B | A or B |
|---|---|--------|
| True | True | True |
| True | False | True |
| False | True | True |
| False | False | False |

### not

**Invierte** el valor booleano.

```python
es_baneado = False

if not es_baneado:
    print("Puede ingresar")
```

Tabla de verdad:

| A | not A |
|---|-------|
| True | False |
| False | True |

Ejemplo combinado:

```python
edad = 25
tiene_carnet = True
tiene_multas = False

if edad >= 18 and tiene_carnet and not tiene_multas:
    print("Puede conducir")
```

## 📝 Comparar textos

También puedes comparar `str`.

```python
nombre = "Cristian"

if nombre == "Cristian":
    print("Bienvenido")
```

Resultado:
```
Bienvenido
```

⚠️ **Ojo: las comparaciones son sensibles a mayúsculas/minúsculas:**

```python
print("Cristian" == "cristian")  # False
print("Hola" == "HOLA")          # False
```

Para comparaciones insensibles a mayúsculas, usa `.lower()`:

```python
nombre = input("Tu nombre: ").lower()

if nombre == "cristian":
    print("Bienvenido Cristian")
```

## 🎲 Anidación

Puedes tener un `if` dentro de otro `if`.

```python
edad = 20
tiene_entrada = True

if edad >= 18:
    if tiene_entrada:
        print("Puedes ingresar")
    else:
        print("Necesitas entrada")
else:
    print("Eres menor de edad")
```

Resultado:
```
Puedes ingresar
```

Ejemplo más profundo:

```python
pais = "Colombia"
edad = 25
tiene_visa = True

if pais == "Colombia":
    if edad >= 18:
        if tiene_visa:
            print("Puedes viajar")
        else:
            print("Necesitas visa")
    else:
        print("Eres menor de edad")
else:
    print("País no reconocido")
```

## ⚡ Condicional ternario

Python permite escribir condicionales en una sola línea:

```python
edad = 20
estado = "Mayor" if edad >= 18 else "Menor"
print(estado)  # Mayor
```

Sintaxis:

```python
valor_si_true if condicion else valor_si_false
```

Ejemplos:

```python
# Calificación
nota = 4.2
resultado = "Aprobado" if nota >= 3 else "Reprobado"

# Descuento
precio = 100
precio_final = precio * 0.8 if precio > 50 else precio

# Género
genero = "Femenino" if sexo == "F" else "Masculino"
```

## 🚀 Casos de uso en automatización

### 1. Validación de edad para registro

```python
edad = int(input("¿Cuántos años tienes? "))

if edad < 13:
    print("❌ Debes tener al menos 13 años")
elif edad < 18:
    print("⚠️  Necesitas consentimiento de tus padres")
else:
    print("✅ Puedes registrarte")
```

### 2. Sistema de descuentos por compra

```python
total_compra = float(input("Total de compra: $"))

if total_compra >= 1000:
    descuento = total_compra * 0.20  # 20%
elif total_compra >= 500:
    descuento = total_compra * 0.10  # 10%
elif total_compra >= 100:
    descuento = total_compra * 0.05  # 5%
else:
    descuento = 0

total_final = total_compra - descuento
print(f"Descuento: ${descuento:.2f}")
print(f"Total a pagar: ${total_final:.2f}")
```

### 3. Calculadora de IMC

```python
peso = float(input("Peso (kg): "))
altura = float(input("Altura (m): "))

imc = peso / (altura ** 2)

if imc < 18.5:
    estado = "Bajo peso"
elif imc < 25:
    estado = "Peso normal"
elif imc < 30:
    estado = "Sobrepeso"
else:
    estado = "Obesidad"

print(f"IMC: {imc:.1f}")
print(f"Estado: {estado}")
```

### 4. Validación de contraseña

```python
contraseña = input("Contraseña: ")

if len(contraseña) < 8:
    print("❌ Contraseña muy corta (mínimo 8 caracteres)")
elif not any(c.isupper() for c in contraseña):
    print("❌ Debe tener al menos una mayúscula")
elif not any(c.isdigit() for c in contraseña):
    print("❌ Debe tener al menos un número")
else:
    print("✅ Contraseña fuerte")
```

### 5. Clasificación de calificaciones

```python
calificacion = float(input("Calificación (0-100): "))

if calificacion >= 90:
    letra = "A"
elif calificacion >= 80:
    letra = "B"
elif calificacion >= 70:
    letra = "C"
elif calificacion >= 60:
    letra = "D"
else:
    letra = "F"

print(f"Tu nota es: {letra}")
```

## 📋 Buenas prácticas

✅ **Usa nombres descriptivos para las variables:**

```python
# Mal
x = 20

# Bien
edad = 20
```

✅ **No escribas condiciones redundantes:**

```python
# Mal
if tiene_carnet == True:
    pass

# Bien
if tiene_carnet:
    pass
```

✅ **Evita bloques muy largos; extrae lógica a funciones:**

```python
# Mal (difícil de leer)
if condicion1 and condicion2 and condicion3:
    print("Hacer algo")
    print("Hacer otra cosa")
    print("Hacer otra cosa más")

# Bien (con función)
def validar_usuario():
    return condicion1 and condicion2 and condicion3

if validar_usuario():
    realizar_acciones()
```

## ✅ Resumen: Lo que debes dominar

### Conceptos clave:

- **Estructura básica**: `if condicion:`, `if condicion: else:`, `if condicion: elif: else:`
- **Operadores de comparación**: `==`, `!=`, `>`, `<`, `>=`, `<=`
- **Operadores lógicos**: `and`, `or`, `not`
- **Indentación**: define los bloques de código en Python — es fundamental
- **Anidación**: condicionales dentro de condicionales
- **Condicional ternario**: línea única

### Checklist de competencias:

- ✅ Escribo condicionales simples con `if`
- ✅ Uso `else` para alternativas
- ✅ Uso `elif` para múltiples opciones
- ✅ Combino condiciones con `and`, `or`, `not`
- ✅ Anido condicionales correctamente
- ✅ Indento adecuadamente
- ✅ Comparo strings y números
- ✅ Resuelvo problemas lógicos con condicionales
