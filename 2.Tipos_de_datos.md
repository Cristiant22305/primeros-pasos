## 📌 INTRODUCCIÓN

Los **tipos de datos** son la forma en que Python clasifica y entiende la información. Son como **etiquetas** que le dicen a Python:
- ¿Es un número?
- ¿Es un texto?
- ¿Es verdadero o falso?

Sin tipos de datos, Python no sabría qué hacer con la información.

---

## ❓ ¿POR QUÉ SON TAN IMPORTANTES?

Observa cómo Python interpreta **diferentes tipos de datos**:

```python
# ¿Cuál es la diferencia?
numero = 20
texto = "20"
```

Ambos se ven iguales, pero:

```python
# Con número (int)
resultado1 = numero + 5  # ✅ Funciona: 25
print(resultado1)

# Con texto (str)
resultado2 = texto + 5   # ❌ Error: no se pueden sumar string + int
```

**Las diferencias en tipos de datos determinan:**
- ✅ Qué operaciones puedes hacer
- ✅ Cómo Python interpreta el dato
- ✅ Cuánta memoria usa
- ✅ Cuán rápido se procesa

## 🎯 SISTEMA DE TIPADO EN PYTHON

### Tipado Dinámico

Python es **débilmente tipado** o **dinámicamente tipado**:

```python
# La misma variable puede cambiar de tipo
valor = 20          # int
print(type(valor))  # <class 'int'>

valor = "veinte"    # str
print(type(valor))  # <class 'str'>

valor = 20.5        # float
print(type(valor))  # <class 'float'>
```

Esto es **flexible pero requiere cuidado**. En automatización, esto es crítico:

```python
# Datos de un API que pueden venir en diferentes formatos
edad_api = "25"                    # API devuelve string
edad_procesada = int(edad_api)     # Convertimos a int
edad_final = float(edad_procesada) # Convertimos a float
```

### Características


### Operaciones Matemáticas

```python

print(a + b)    # 13 - Suma
```


## ⚠️ PRECISIÓN Y LIMITACIONES DE FLOAT

### El Problema de Precisión

```python
# Esto es un problema COMÚN en programación
resultado = 0.1 + 0.2
print(resultado)  # 0.30000000000000004 (¡NO es 0.3!)
```

**¿Por qué ocurre?**
Los decimales en binario (cómo guarda Python) no pueden representar exactamente 0.1 y 0.2.

### Soluciones

```python
# Opción 1: Usar redondeo
resultado = round(0.1 + 0.2, 2)
print(resultado)  # 0.3

# Opción 2: Usar Decimal para precisión (en finanzas)
from decimal import Decimal
resultado = Decimal("0.1") + Decimal("0.2")
print(resultado)  # 0.3 (exacto)

# Opción 3: Formato en string (para mostrar)
resultado = 0.1 + 0.2
print(f"{resultado:.2f}")  # 0.30
```

### En Automatización Financiera

```python
# INCORRECTO - puede haber errores
saldo = 1000.00
pago1 = 0.1
pago2 = 0.2
saldo = saldo - pago1 - pago2
print(saldo)  # 999.6999999999999

# CORRECTO - usar Decimal para dinero
from decimal import Decimal
saldo = Decimal("1000.00")
pago1 = Decimal("0.10")
pago2 = Decimal("0.20")
saldo = saldo - pago1 - pago2
print(saldo)  # 999.70 (exacto)
```

## 📍 INDEXACIÓN Y SLICING EN STRINGS

### Slicing (Obtener porciones)

```python
texto = "Python"
# Índices: 012345

print(texto[0:2])    # Py (desde 0 hasta 2, sin incluir 2)
print(texto[2:4])    # th
print(texto[:3])     # Pyt (desde inicio hasta 3)
print(texto[3:])     # hon (desde 3 hasta final)
print(texto[::-1])   # nohtyP (invertido)

# En automatización: extraer partes de texto
```

## 🔄 CONVERSIONES ENTRE TIPOS

### Tabla de Conversiones

| De/A | int | float | str | bool |
|------|-----|-------|-----|------|
| int | — | float(x) | str(x) | bool(x) |
| float | int(x) | — | str(x) | bool(x) |
| str | int(x)* | float(x)* | — | bool(x) |
| bool | int(x) | float(x) | str(x) | — |

*Solo si el string contiene el número

### Ejemplos Prácticos

```python

y = int(x)
print(y)  # 3 (no redondea)

# str → int (si es válido)
x = "42"
y = int(x)
print(y)  # 42

# int → str
x = 100
y = str(x)
print(f"Tengo {y} manzanas")  # Tengo 100 manzanas

# bool → int
print(int(True))   # 1
print(int(False))  # 0
```

## ❌ ERRORES COMUNES EN CONVERSIONES

### Error 1: Convertir string no válido

```python
# ❌ Error
numero = int("abc")  # ValueError: invalid literal for int() with base 10: 'abc'

# ✅ Solución: Validar primero
texto = "abc"
if texto.isdigit():
    numero = int(texto)
else:
    print("No es un número válido")
```

### Error 2: Olvidar convertir input()

```python
# ❌ Error
edad = input("Edad: ")
print(edad + 5)  # TypeError: can only concatenate str (not "int") to str

# ✅ Solución
edad = int(input("Edad: "))
print(edad + 5)  # Funciona correctamente
```

### Error 3: Confundir tipos en operaciones

```python
# ❌ Error
resultado = "10" + 5  # TypeError: can only concatenate str (not "int") to str

# ✅ Soluciones
resultado1 = int("10") + 5      # 15
resultado2 = "10" + str(5)      # "105"
resultado3 = float("10") + 5    # 15.0
```

### Error 4: Truncamiento al convertir a int

```python
# ⚠️ Comportamiento inesperado
print(int(3.9))   # 3 (no redondea, trunca)
print(int(3.1))   # 3

# ✅ Si necesitas redondear
print(round(3.9))   # 4
print(round(3.1))   # 3
```

## 📝 F-STRINGS AVANZADOS

### Formato Básico

```python
nombre = "Cristian"
edad = 24

# Básico
print(f"Me llamo {nombre}")  # Me llamo Cristian

# Múltiples variables
print(f"{nombre} tiene {edad} años")  # Cristian tiene 24 años

# Expresiones
print(f"El próximo año tendré {edad + 1}")  # El próximo año tendré 25
```

### Formato de Decimales

```python
precio = 99.99
iva = 0.19

# .2f = 2 decimales con redondeo
print(f"Precio: ${precio:.2f}")  # Precio: $99.99

# .0f = sin decimales
print(f"Cantidad: {100.5:.0f}")  # Cantidad: 100 (redondea)

# Con operaciones
print(f"Total: ${precio * (1 + iva):.2f}")  # Total: $118.98
```

### Formato de Números Grandes

```python
dinero = 1000000

# :, = separador de miles
print(f"Dinero: ${dinero:,}")  # Dinero: $1,000,000

# Combinado con decimales
precio = 1234.56
print(f"Precio: ${precio:,.2f}")  # Precio: $1,234.56
```

### Alineación y Relleno

```python
# Alineación
print(f"|{nombre:<10}|")   # Alineado a izquierda
print(f"|{nombre:>10}|")   # Alineado a derecha
print(f"|{nombre:^10}|")   # Centrado

# Relleno
print(f"{precio:0>10.2f}")  # Rellena con 0s: 0000099.99
```

### Nivel 4️⃣: EXPERTO

#### Ejercicio 4.1: Sistema de normalización de datos

```python
# TODO: Crea un sistema que normalice diferentes formatos
# Entrada: datos en diversos formatos (strings, números)
# Salida: datos normalizados y validados
```

**Solución:**
```python
def normalizar_datos(datos_entrada):
    """Normaliza y valida datos"""
    
    # Procesar según tipo
    if isinstance(datos_entrada, str):
        datos = datos_entrada.strip().lower()
        if datos.isdigit():
            return int(datos)
        elif "." in datos and all(c.isdigit() or c == "." for c in datos):
            return float(datos)
        else:
            return datos
    
    elif isinstance(datos_entrada, (int, float)):
        return datos_entrada
    
    return None

# Pruebas
print(normalizar_datos("  123  "))      # 123 (int)
print(normalizar_datos("  45.67  "))    # 45.67 (float)
print(normalizar_datos("  HOLA  "))     # "hola" (str)
print(normalizar_datos(100))            # 100 (int)
print(normalizar_datos(99.99))          # 99.99 (float)
```
